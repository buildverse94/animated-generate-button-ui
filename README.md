# ✨ Glowing Generate Site Button UI

A modern and attractive **Generate Site Button UI** built using **HTML, CSS, JavaScript, and Tailwind CSS**. This project features a glowing purple theme, smooth animations, and a clean user interface suitable for modern web applications.

## 🚀 Preview

A stylish animated button with:

* Purple glowing effect
* Smooth hover animations
* Modern UI design
* Responsive layout
* Clean and reusable code

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
